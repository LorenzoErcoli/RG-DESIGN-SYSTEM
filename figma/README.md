# Figma

Questa cartella documenterà il collegamento tra i token del repository e la libreria Figma RG. Il codice resta la fonte portabile; Figma rappresenta componenti, varianti e composizioni approvate.

## Mappatura prevista

- Variables: colori permanenti, neutri, stagionali, spacing, radius e layout.
- Text styles: Identity, Body e Mono con scale definite in `tokens.json`.
- Components: button, field, badge, table primitives, navigation e card.
- Templates: Archive, Review, Consumption, Knowledge, Rulebook e Dashboard.

## Regole di sincronizzazione

1. Usare gli stessi nomi semantici dei token, adattati alla sintassi Figma (`color/action/primary`).
2. Non pubblicare una palette stagionale come alias delle azioni primarie.
3. Annotare versione e data di ogni sincronizzazione.
4. Risolvere le divergenze aggiornando fonte e changelog nello stesso intervento.
